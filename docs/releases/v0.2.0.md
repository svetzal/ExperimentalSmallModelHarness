# Microgentic 0.2.0

This release makes the conversation view easier to read and to steer while a
small model works.

- The view has colour that follows your terminal theme. Set `NO_COLOR` to turn
  colour off; labels and glyphs keep their meaning without it.
- Slash commands stay local and never reach the model. `/model` and `/effort`
  open arrow-key pickers, or take a value directly. `/clear` starts a new
  conversation and `/help` lists the commands. The footer suggests matching
  commands as you type, and Tab completes them.
- Each tool call is one line with a short summary of its parameters, such as the
  file and line range it read. A spinner marks a running call, then a check or a
  cross shows its result.
- The model's thinking streams in dim italics while it works. When it finishes,
  thinking that led to tool calls shrinks to its last line above those calls,
  and thinking before a reply is removed.
- Whitespace-only output from the model no longer opens blank rows.
- A status bar shows the model, reasoning effort, project folder, Git branch and
  changes, and how full the context window is. The context figure is the
  runtime's own estimate; without a known window size it shows a token count.
- A short launch animation plays when the view opens. Any key skips it, and the
  key still reaches the input. Set `MICROGENTIC_NO_ANIMATION=1` to turn it off.

Changes from `/model` and `/effort` last for the session. Use `microgentic setup`
to change your defaults. Changing either setting after the first message starts
a new conversation, because a conversation keeps the model and effort it began
with.

Benchmark mode, `microgentic run`, and trace records are unchanged.

Install or upgrade through Homebrew:

```sh
brew upgrade svetzal/tap/microgentic
```
