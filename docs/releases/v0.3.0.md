# Microgentic 0.3.0

This release gives the agent a calculator, lets it read project guidance, and
makes the conversation view easier to read.

- **Project guidance.** Microgentic reads `AGENTS.md` files from the project
  directory up to the Git root, with `CLAUDE.md` as a fallback where a directory
  has no `AGENTS.md`. A personal file at `~/.config/microgentic/AGENTS.md`
  applies everywhere. Deeper files win when guidance conflicts. A nested file
  below the project directory is delivered when the agent first works in its
  directory. Guidance cannot grant permissions or change the available tools.
  Use `/guidance` in the conversation to see what loaded; the status bar shows
  a 📜 count. `microgentic run --no-project-guidance` turns discovery off.
- **Calculator.** A `calculate` tool evaluates arithmetic exactly, so the model
  does not have to work sums out in its head. It accepts batches, and a line
  can name a value for later lines. The conversation view shows each result on
  the tool line.
- **Word wrapping.** Text wraps at words and no row starts with a stray space.
  Indentation and list items keep their shape. Tokens too long for a row are
  split at a natural break or shortened in the middle with `…`. The Evidence
  path is never shortened.
- **Spacing.** Reply text that follows thinking or tool lines has a blank row
  above it.
- **Launch animation.** It now plays in about 1.3 seconds.

Benchmark mode is unchanged: it offers no calculator and reads no project
guidance, and its provider requests are identical to 0.2.0.

Install or upgrade through Homebrew:

```sh
brew upgrade svetzal/tap/microgentic
```
