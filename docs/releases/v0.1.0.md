# Microgentic 0.1.0

Microgentic is an adaptive coding agent optimized for small models that need help
staying on task. This first public package brings the experimental harness into
a small terminal interface for everyday use.

- Start an ongoing, streamed conversation with `microgentic`.
- Configure oMLX or Ollama, a default model, and reasoning effort with
  `microgentic setup`.
- Send prompts through stdin or `--prompt`; redirect results and diagnostics
  separately.
- Inspect, edit, and check projects through the existing scoped runtime.
- Keep benchmark tasks isolated with `microgentic benchmark run`.
- Review preserved traces with the native analyzer and transcript renderer.

Install through Homebrew:

```sh
brew install svetzal/tap/microgentic
microgentic setup --apply
microgentic
```

Packages cover Apple Silicon, Intel Mac, and Linux x86-64. The release includes
checksums, binary manifests, and embedded source revisions. `mg` remains an optional
shell alias; the compatibility executable remains available.

This is an early release. Work permissions and approval previews, durable session
resume, additional gateways, and richer tool inspection remain preparation work.
The current runtime can edit files and run commands when you request work.
Provider credentials and server URLs remain in their existing environment variables.
A successful process exit still needs inspection of the native terminal result
when classifying benchmark outcomes.
